# Project preferences

- Use concise, neutral academic/research-project wording in the website, README
  and public documentation. Describe configurations, tools and measured values
  without qualitative judgments about the project or image quality.
- Keep numerical results, experiment provenance and operational validation accurate.
- Place the single note "Research project only. Not for real medical use." at the
  end of public pages and documents, rather than leading with it.
- Keep the website focused on MRI tools, dataset exploration, sampling,
  measurements and short terminology help. Keep report-writing and presentation
  material in repository documentation, outside the website navigation.
- Prefer focused checks and completion over additional lengthy experiment or
  browser sweeps unless a concrete change requires them.
- Remove completed one-off audit tools and disposable outputs after checking
  references. Keep application dependencies and the automated CI regression suite.
- Publish finished, checked changes to GitHub as requested and keep the working
  directory clean.
